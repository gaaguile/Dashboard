# Dashboard

A dashboard for tracking market, macro, and portfolio data.

## Local setup

1. Copy `.env.example` to `.env.local`.
2. Replace the sample credentials with your own values.
3. Run `npm install` and then `npm run dev`.

The app reads `VITE_DASHBOARD_USERNAME` and `VITE_DASHBOARD_PASSWORD` from the Vite environment so credentials are not hardcoded in the source tree.
